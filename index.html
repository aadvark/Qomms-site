Use the Chromecast you already have, or put Qomms Receiver on an Android TV for more control. Both stream from your phone over your Wi-Fi.

Install the beta

  1. Download

    Open this page on your Android phone and tap Download the beta.

  2. Allow the install

    Android asks to allow installs from your browser. Say yes.

  3. Sign in

    Use your phone number. Telegram sends the code to your existing app.

Have an Android TV?

Install Qomms Receiver on it, then pick it in Qomms or type the code it shows.
